## Round 1: claude (CRITIQUE)

```text
Round 1 proposal. I haven't read the drawio files or the specs, so these resolutions rest only on the audit summaries in the topic.

1. **N-01:** The Excel Copy Editor works on a server-side `working_copies` DB table. It holds the parsed rows as JSON, with a TTL of 24h and a cap of 5 copies per user. It never writes files to disk. Only admin edits `assigned_to`, `deadline` and `date_filed`, and reassignment follows 016.
4. **N-04:** Bulk restore is allowed for supervisor and admin only. A regular user cannot restore, singly or in bulk, which matches 006 and appbuild. Fix 015.
5. **N-05:** Return 404 for any case outside the user's scope or non-existent, so existence is never leaked. 403 is reserved for role-gated endpoints, such as admin routes called by a non-admin. Fix 007 to say this.
6. **N-06:** All case mutations go through one service layer. Single-case PATCH, PUT and DELETE require `version` and return 409 on mismatch. Import, archive/restore, bulk and reassign operate per row, increment `version`, and report conflicts per row. The only exception is bulk/import, which may skip a row that has changed since its preview. Add `version` to the 002/003 examples.
7. **N-07:** Only admin may set or change `deadline` and `date_filed`, including on creation. A non-admin POST that includes dates gets 403. A non-admin creates a case with null dates, and the admin fills them in. An admin date edit requires a `reason` string, which is logged in the audit log (009).
8. **N-08:** Past deadlines are allowed everywhere, since overdue cases are valid. Creation by admin and import both accept them. 12. **N-12:** Bulk operations are in scope. Remove them from the Out of Scope sections of 003 and 006 and cross-reference 015 and 016.
13. **N-13:** The archive shows cases where the user is currently assigned, or was assigned according to the `case_assignment_history` table that 016 adds. Supervisors also see their subordinates' archived cases. Admin sees all.
14. **N-14:** `GET /api/cases` always returns `{items, total, page, page_size}`. Fix 002/003/006 to match. Supervisors get an additional `GET /api/cases/summary` with per-member totals.
15. **N-15:** The Dashboard lives at `/` and Main (the case table) moves to `/cases`. Login redirects to `/`. The 7-day colour and `due_this_week` logic use `notification_threshold_days` from settings, with a default of 7. Update AGENTS.md routes.
16. **N-16:** "Zaległe" means `deadline < today`, strictly. The link uses `deadline_to=yesterday`, or a dedicated `overdue=true` param, which is better. Today's deadline counts as "due today", not overdue.
17. **N-17:** Keep the 60-minute JWT, with no refresh token for now. `is_active` is already checked on every request, so deactivation takes effect immediately. There is no inactivity timer. On a 401 the frontend saves unsaved edit drafts to `sessionStorage` and shows a re-login modal that restores them. That satisfies 011's no-silent-data-loss rule.
18. **N-18:** The minimum password length is 12 everywhere, so 008 follows 007. Admin-created users and admin resets get `must_change_password=true`. While it is set, only `/api/me` and the password-change endpoint work.
19. **N-19:** `notifications_sound` is out of scope. Remove it from the 008 story and example, and keep the Out of Scope entry.
20. **N-20:** The JWT carries only `sub`. Role and `is_active` are loaded from the DB on each request. Fix 002 and keep `security.py` as it is.
21. **N-21:** The Admin Panel has 4 tabs: Users, Settings (threshold and so on), Audit log, Backups. Update 012 to match. Import and the Editor are reached from Main through an "Import / Edytor pliku" button, not from the Admin Panel.

Deactivating a supervisor requires choosing a new supervisor for their subordinates, or it falls back to the admin. Without that choice the API returns 409 and lists the affected cases and subordinates.

Support "notatka do osoby" via nullable `case_id` and nullable `subject_user_id` with a DB `CHECK (case_id IS NOT NULL OR subject_user_id IS NOT NULL)`, scoped to author, subject, subject's supervisor, and admin for person-only notes.
